# Fares Ayman — Developer Portfolio (ファレス・アイマン)

An anime and Japanese cultural-inspired web portfolio engineered for **Fares Ayman** — Data Analyst at Valeo and Backend Architecture / Full-Stack Engineer.

Built with a light/dark mode daylight Japanese aesthetic, floating canvas sakura blossom particles, traditional ambient Koto sound loops, interactive filterable mission archives, an integrated Formspree contact form, and a dynamic daily/hourly quote generator.

---

## 🌟 Key Features

* 🏯 **Japanese Cultural & Anime Aesthetics:** Custom Torii Gate header accents, Washi paper textures, Seigaiha wave patterns, Hanko stamp graphics, and a Japanese dynamic SVG favicon.
* 🌸 **Interactive Sakura Canvas:** Canvas-based cherry blossom particle animation rendered dynamically across all viewports.
* 🎵 **Ambient Audio Player & Web Synthesizer:** Integrated HTML5 audio loop with a custom Web Audio API synthesizer fallback and animated equalizer visualizer bars.
* ☀️/🌙 **Seamless Light & Dark Mode:** Defaults to a clean daylight theme with local storage persistence and smooth theme toggling.
* 📜 **Daily & Hourly Wisdom Quote Generator:** Rotates inspirational life and tech quotes automatically based on time calculations.
* 🎯 **Filterable Mission Archives:** Dynamic category filtering for Java/Backend, Power BI & Data Analytics, and React/Angular projects.
* 📬 **Live Contact Infrastructure:** Fully integrated Formspree API contact form for instant email delivery directly to your inbox.
* 📱 **Fully Responsive:** Mobile-first layout optimized across all viewports, including ultra-wide 32"+ monitors.

---

## 🛠️ Built With

* **HTML5** — Semantic structure & custom SVG icons
* **Tailwind CSS** — Modern utility-first styling & dark mode support
* **Vanilla JavaScript (ES6+)** — Interactive DOM manipulation, theme persistence, Formspree AJAX delivery, and particle canvas rendering
* **Formspree API** — Direct-to-email form submission backend
* **FontAwesome 6** — Scalable icon set
* **Google Fonts** — *Cinzel*, *Noto Serif JP*, and *Zen Kaku Gothic New*

## 🚀 Getting Started

1. **Clone the Repository:**
   ```bash
   git clone [https://github.com/Faresaymann/Portfolio.git](https://github.com/Faresaymann/Portfolio.git)
   cd Portfolio
   ```

2. **Open in Browser:**
   Simply double-click `index.html` or open it using any web browser.

3. **Deploy on GitHub Pages:**
   * Go to your repository **Settings** → **Pages**.
   * Under **Build and deployment**, select **Deploy from a branch**.
   * Set branch to `main` / `/ (root)` and click **Save**.
